### 🏗️ Why is KALKI AI different?

We built KALKI on a 7-layer modular architecture to solve the typical latency, safety, and memory challenges of enterprise AI:

1. **6-Agent Orchestration**: Specialised Planner, Research, Memory, Executor, Validator, and Security agents communicating asynchronously via **MCP (Model Context Protocol)** and **A2A IPC**.
2. **Hybrid RAG Retrieval**: Computes Reciprocal Rank Fusion (RRF) dense vector search + BM25 keyword matching with Cross-Encoder re-ranking.
3. **5-Tier Hierarchical Memory**: Structured Short-term, Long-term, Semantic, Episodic, and Procedural memory states.
4. **Defensive Cybersecurity Guard**: In-line AI safety filters, threat score assessment, NIST compliance logs, and Human-in-the-Loop workflows.
5. **Edge SLM Integration**: Quantized INT4 SLMs (Phi-3 / Llama-3.2) optimized for local, offline execution on mobile and IoT.
