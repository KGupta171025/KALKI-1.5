# Security Policy

## Supported Versions

We actively monitor and fix security vulnerabilities on the following versions:

| Version | Supported |
| ------- | --------- |
| 1.5.x   | Yes       |
| < 1.5.0 | No        |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

If you discover a potential vulnerability or safety bypass in the KALKI AI guardrail layers, please report it responsibly:

1. Send an email to the maintainer at `hg497kg@gmail.com`.
2. Include a detailed description of the vulnerability, steps to reproduce, and a proof-of-concept (PoC) if applicable.
3. We will acknowledge receipt of your report within 48 hours and work with you to resolve it.

## Scope of Safety Audits
KALKI AI is built for **defensive cybersecurity monitoring and auditing**. Any use of the agent execution loops to target non-authorized resources, accounts, or services is strictly prohibited and outside the scope of ethical maintenance.
